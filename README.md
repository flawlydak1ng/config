# Конфигурационный язык → XML

Транслятор учебного конфигурационного языка, вариант 25. Утилита читает UTF-8-файл,
вычисляет константы в порядке объявления и записывает XML в UTF-8.
Для синтаксического разбора используется библиотека **pyparsing**.

## Установка и запуск

Требуется Python 3.9 или новее. Для первоначальной установки зависимости нужен доступ к PyPI.
На macOS и Linux из корня проекта выполните:

```sh
make setup
make test
mkdir -p out
make run INPUT=examples/library.cfg OUTPUT=out/library.xml
cat out/library.xml
```

Команда без Make и справка по флагам:

```sh
PYTHONPATH=src .venv/bin/python -m configxml -i examples/library.cfg -o out/library.xml
PYTHONPATH=src .venv/bin/python -m configxml --help
```

На Windows (PowerShell):

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
.\.venv\Scripts\python -m unittest discover -s tests -v
New-Item -ItemType Directory -Force out | Out-Null
.\.venv\Scripts\python -m configxml -i examples/library.cfg -o out/library.xml
Get-Content -Encoding UTF8 out/library.xml
```

Оба параметра обязательны. `-i` / `--input` задаёт исходный файл,
`-o` / `--output` — файл результата в существующей папке.
При успехе код возврата равен 0. Ошибки аргументов дают код 2,
ошибки чтения, трансляции или записи — 1. Диагностика выводится в stderr.
При ошибке трансляции прежнее содержимое выходного файла сохраняется.

## Язык

Документ содержит последовательность объявлений и значений.
Пробельные символы разделяют лексемы. Комментарий начинается с `//`
вне строки и продолжается до конца строки. Пустой документ допустим.

| Конструкция | Синтаксис и результат |
|---|---|
| Число | Цифры, точка и необязательная дробная часть, например `0.125` или `7.`. |
| Строка | Текст в одинарных кавычках на одной строке, например `'север & юг'`. Экранирование не задано. |
| Массив | `list()`, `list(1., 'x', list(2.))`. Порядок и типы элементов сохраняются. |
| Константа | `def rate := 2.5;`. Имя состоит из строчных латинских букв. Повторное объявление — ошибка. |
| Выражение | `^[оператор операнды]`. Операндом может быть значение, объявленное ранее имя или выражение. |
| Арифметика | `^[+ a 1]`, `^[- a 1]`, `^[* a 2]`, `^[/ a 2]`. Ровно два числовых операнда. |
| Длина | `^[len 'кот']` даёт 3. Для массива учитываются только элементы верхнего уровня. |

В выражениях допустима целая запись операнда, как в примере `^[+ a 1]` из условия.
Вне выражения числу нужна десятичная точка. Арифметика использует Decimal с точностью
28 значащих цифр и округлением к ближайшему чётному при равноудалённых результатах.
Деление на ноль, ссылка на неизвестное имя и неверный тип операнда вызывают ошибку.

## Формат XML

Корень документа — `config`. Объявлению соответствует `constant` с атрибутом `name`.
Теги `number`, `string` и `list` сохраняют типы значений. Самостоятельные значения
становятся дочерними элементами корня. Выражения заменяются результатами вычисления.

Вход:

```
def hours := 2.;
list(^[* hours 3], 'A & B')
```

Выход:

```xml
<?xml version='1.0' encoding='utf-8'?>
<config>
  <constant name="hours">
    <number>2</number>
  </constant>
  <list>
    <number>6</number>
    <string>A &amp; B</string>
  </list>
</config>
```

## Примеры

| Входной файл | Что вычисляется | Результат |
|---|---|---|
| `examples/library.cfg` | Недельный лимит выдачи и число жанров | `limit = 21`, `sections = 3` |
| `examples/studio.cfg` | Средняя длительность двух сцен | `average = 20` секунд |
| `examples/garden.cfg` | Объём воды на грядку за вычетом резерва | `perbed = 4.0` |

```sh
make run INPUT=examples/studio.cfg OUTPUT=out/studio.xml
make run INPUT=examples/garden.cfg OUTPUT=out/garden.xml
```

## Устройство программы

- `src/configxml/grammar.py` строит грамматику. Рекурсивные правила связывают значения,
  массивы и выражения. Узел сохраняет позицию начала конструкции.
- `src/configxml/translator.py` содержит функцию `translate(source)`. Она разбирает текст,
  вычисляет узлы с таблицей констант и возвращает XML в виде байтов UTF-8.
  При ошибке исходного документа возбуждается `ConfigError`.
- `src/configxml/__main__.py` разбирает аргументы, читает вход и заменяет файл результата.
- `tests/` содержит модульные тесты и проверки CLI через отдельный процесс.

Переменные Makefile: `PYTHON` выбирает интерпретатор для установки,
`VENV` — путь для виртуального окружения, `INPUT` и `OUTPUT` — пути для цели `run`.
